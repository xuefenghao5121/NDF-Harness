# Product tree skeleton

Install these empty directories under `spec/`. **Write only this project's product contracts here.**

```text
00-charter/       # charter, product glossary
10-architecture/
20-behavior/      # product L0/L1 only — no process long-form
30-interfaces/
40-constraints/   # product SLA / constants
50-verification/
open/             # Pending product proposals only
decisions/        # product DEC / ADR
models/           # L3 reference models (not experiments)
```

Also create `spec/archive/` (sot: false) when closing proposals.

First product clause: follow `../CLAUSE-FORMAT.md`. Process rules stay in `spec/meta/`.
